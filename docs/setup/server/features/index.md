# Anticensor-Specific Features

Anticensor extends Spacebar with additional features and configuration options. For detailed information about these features, see the following documentation:

- [User Consent Management](consents.md) - GDPR-compliant consent tracking system
- [Lobby System](lobbies.md) - Ephemeral matchmaking and coordination lobbies
- [Thread Promotion](thread-promotion.md) - Convert threads to top-level channels
- [Volatile Mode](volatile-mode.md) - In-memory database for testing and development
- [Configurable Limits](configurable-limits.md) - Comprehensive limit configuration system
- [Anticensor Enhancements](anticensor-enhancements.md) - Additional feature enhancements including:
    - Slowmode with arbitrary seconds support
    - PIN_MESSAGES permission split from MANAGE_MESSAGES
    - Doubly-linked replies for conversation threading
    - Guild template support (including Discord.com templates)
    - Privacy gating for third-party connections
    - Presence suppression by rights
    - OAuth2 bot installation enhancements
